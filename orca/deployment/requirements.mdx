---
title: "Prerequisites"
description: "Environment requirements before installing ORCA."
---

<Note>Draft skeleton. Owner: SRE lead.</Note>

- Kubernetes version and supported distributions
- Storage classes: block (datastores) + object (MinIO)
- Network/firewall matrix — ports per component
- DNS, TLS, and PKI requirements
- Identity provider (OIDC/SAML)
- Access to source tools: Splunk, ServiceNow, AppDynamics, PagerDuty, Grafana, Datadog, New Relic
- Sovereign / data-residency profile notes
