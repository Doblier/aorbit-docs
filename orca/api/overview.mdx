## API surface

- **Event ingestion** — push events from custom sources.
- **Incident query** — search and retrieve enriched incidents.
- **Correlation explain** — retrieve the evidence trail for any grouping (why these events, which graph dependencies).
- **Remediation approval** — programmatic approve/reject for guided remediation.
- **Admin/config** — suppression rules, thresholds, connectors.
