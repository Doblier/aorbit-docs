Every ORCA deployment passes a gated readiness framework with defined entry/exit criteria and named sign-offs. Sign-off roles span streaming, SRE, deployment, data, schema, and compliance; the evidence bundle is archived per gate.

<Note>Define gates 1–5 from the engagement playbook (install verified · sources connected · data quality · SLOs met · security review), then remove this note. Owner: SRE lead.</Note>

## Shadow mode — six weeks

ORCA runs alongside existing operations with no production actions for **six weeks, not four**: the window must cover **month-end + a T1 change window + off-hours** — the key test of suppression correctness. Four weeks can miss a maintenance window entirely.
